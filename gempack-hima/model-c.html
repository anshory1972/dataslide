Model C: five farm products

Model B for five products at once. You learn sets and the (all,i,COM) statement, so one equation is written once for every product.

Arief Anshory Yusuf, Faculty of Economics and Business, Universitas Padjadjaran

The model

The equations are the same as in Model B. Each product i has its own price, quantity and elasticities. Income and rainfall are the same for all products.

Demand:  Q(i) = DSHIFT(i) × P(i)^(−EPSD(i)) × INC^EPSY(i)
Supply:  Q(i) = SSHIFT(i) × P(i)^EPSS(i) × RAIN^EPSR(i)
Value:   VALUE(i) = P(i) × Q(i)

Files

Download model-c.zipdryyear.cmf, marketc.har, marketc.tab

Unzip the file. It creates a folder model-c.

marketc.tab

! Model C: five farm products, one rainfall variable            !
!   Demand:  Q(i) = DSHIFT(i) * P(i)^(-EPSD(i)) * INC^EPSY(i)     !
!   Supply:  Q(i) = SSHIFT(i) * P(i)^EPSS(i) * RAIN^EPSR(i)       !

EQUATION (DEFAULT = LEVELS) ;
VARIABLE (DEFAULT = LEVELS) ;
FORMULA (DEFAULT = INITIAL) ;
COEFFICIENT (DEFAULT = PARAMETER) ;

File DATA # Transaction data, income, rainfall and elasticities # ;

Set COM # Farm products # (Rice, Maize, Cassava, Vegetables, Fruits) ;

! Elasticities, one value for each product !
Coefficient (all,i,COM) EPSD(i) # Price elasticity of demand, positive # ;
Coefficient (all,i,COM) EPSY(i) # Income elasticity of demand # ;
Coefficient (all,i,COM) EPSS(i) # Price elasticity of supply # ;
Coefficient (all,i,COM) EPSR(i) # Rainfall elasticity of supply # ;
Read EPSD from file DATA header "EPSD" ;
Read EPSY from file DATA header "EPSY" ;
Read EPSS from file DATA header "EPSS" ;
Read EPSR from file DATA header "EPSR" ;

! Variables for each product !
Variable (all,i,COM) P(i)      # Price, Rp per kg # ;
Variable (all,i,COM) Q(i)      # Quantity, billion kg # ;
Variable (all,i,COM) VALUE(i)  # Value of transactions, Rp billion # ;
Variable (all,i,COM) DSHIFT(i) # Other demand factors # ;
Variable (all,i,COM) SSHIFT(i) # Other supply factors # ;

! Variables shared by all products !
Variable INC  # Household income, Rp trillion # ;
Variable RAIN # Rainfall, mm per year # ;

! Observed data !
Read P     from file DATA header "PRIC" ;
Read VALUE from file DATA header "VAL" ;
Read INC   from file DATA header "INC" ;
Read RAIN  from file DATA header "RAIN" ;

Formula (all,i,COM) Q(i) = VALUE(i) / P(i) ;

! Calibration !
Formula (all,i,COM) DSHIFT(i) = Q(i) / [P(i)^(-EPSD(i)) * INC^EPSY(i)] ;
Formula (all,i,COM) SSHIFT(i) = Q(i) / [P(i)^EPSS(i) * RAIN^EPSR(i)] ;

! Equations, one of each for every product !
Equation E_DEMAND # Demand curve #
  (all,i,COM) Q(i) = DSHIFT(i) * P(i)^(-EPSD(i)) * INC^EPSY(i) ;
Equation E_SUPPLY # Supply curve #
  (all,i,COM) Q(i) = SSHIFT(i) * P(i)^EPSS(i) * RAIN^EPSR(i) ;
Equation E_VALUE  # Value of transactions #
  (all,i,COM) VALUE(i) = P(i) * Q(i) ;
  • The Set statement lists the five products. The names must have no spaces.
  • (all,i,COM) means that the statement holds for every product. One line in the model file gives five equations.

dryyear.cmf

! Rainfall falls by 20 percent !
auxiliary files = marketc ;
file DATA = marketc.har ;
updated file DATA = <cmf>.upd ;
exogenous p_INC p_RAIN p_DSHIFT p_SSHIFT ;
rest endogenous ;
shock p_RAIN = -20 ;
method = gragg ;
steps = 2 4 6 ;
verbal description = Rainfall falls by 20 percent ;
log file = yes ;

Run it

In WinGEM. Choose File → Change both default directories and select the folder of this exercise. Choose Simulation → TABLO Implement, keep GEMSIM selected, open marketc.tab and click Run. Click Go to GEMSIM, open dryyear.cmf and click Run. Then click Go to ViewSOL to see the results.

In the Command Prompt. Go to the folder of this exercise and type:

tablo -pgs marketc
gemsim -cmf dryyear.cmf

Each program should end with (The program has completed without error.)

Results

Rainfall falls by 20%. It is one shock, but the effect differs by product.

ProductPrice, %Quantity, %Value, %
Rice8.73−4.104.27
Maize7.11−5.341.38
Cassava2.26−1.330.90
Vegetables7.72−5.072.26
Fruits2.83−2.750.00

The rice result is the same as in Model B, because rice has the same data.

The price of each product changes by the factor 0.8^(−EPSR/(EPSD + EPSS)). Products with a larger rainfall elasticity of supply have larger price rises. Cassava has the smallest rainfall elasticity, so its price rises least.

The value of fruit sales does not change. Demand for fruits has a price elasticity of 1.0, so price and quantity change by the same percentage in opposite directions.

Try this

  1. Give fruits a price elasticity of demand of 0.5 in the data file and run again. Does the value of fruit sales still stay the same?
  2. Shock rainfall by −20% and income by 5% together. Which product has the largest price rise?
