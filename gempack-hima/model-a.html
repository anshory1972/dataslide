Model A: one market

Demand and supply for one product. You learn the parts of a TAB file, calibration, a closure, a shock and a multi-step solution.

Arief Anshory Yusuf, Faculty of Economics and Business, Universitas Padjadjaran

The model

Demand and supply both have constant elasticities:

Demand:Q=D P−εdSupply:Q=S Pεs\begin{aligned} \text{Demand:}\quad Q &= D\,P^{-\varepsilon^{d}} \\ \text{Supply:}\quad Q &= S\,P^{\varepsilon^{s}} \end{aligned}Demand:QSupply:Q​=DP−εd=SPεs​

The quantity is not in the data. The model computes it as value divided by price, which gives 30 billion kg.

Calibration

DDD and SSS are not observed. The model chooses them so that both curves pass through the observed price P0P_0P0​ and quantity Q0Q_0Q0​:

Q0=V0P0,D=Q0P0−εd,S=Q0P0εsQ_0 = \frac{V_0}{P_0}, \qquad D = \frac{Q_0}{P_0^{-\varepsilon^{d}}}, \qquad S = \frac{Q_0}{P_0^{\varepsilon^{s}}}Q0​=P0​V0​​,D=P0−εd​Q0​​,S=P0εs​Q0​​

V0V_0V0​ is the value of transactions in the data. These are the three Formula statements before the equations. GEMPACK then starts from a known solution: the data.

Files

Download model-a.zipdemand10.cmf, market.har, market.tab

Unzip the file. It creates a folder model-a with the three files.

market.tab

! One market with constant-elasticity demand and supply !
!   Demand:  Q = DSHIFT * P^(-EPSD)                      !
!   Supply:  Q = SSHIFT * P^EPSS                         !

EQUATION (DEFAULT = LEVELS) ;
VARIABLE (DEFAULT = LEVELS) ;
FORMULA (DEFAULT = INITIAL) ;
COEFFICIENT (DEFAULT = PARAMETER) ;

File DATA # Transaction data and elasticities # ;

! Data !
Coefficient VALUE # Value of transactions, Rp billion # ;
Coefficient EPSD  # Price elasticity of demand, as a positive number # ;
Coefficient EPSS  # Price elasticity of supply # ;
Read VALUE from file DATA header "VAL" ;
Read EPSD  from file DATA header "EPSD" ;
Read EPSS  from file DATA header "EPSS" ;

! Variables !
Variable P      # Price, Rp per kg # ;
Variable Q      # Quantity, billion kg # ;
Variable DSHIFT # Position of the demand curve # ;
Variable SSHIFT # Position of the supply curve # ;

! Observed price, read from the data !
Read P from file DATA header "PRIC" ;

! Quantity follows from value and price !
Formula Q = VALUE / P ;

! Calibration: choose the shifters so that both curves pass through the data !
Formula DSHIFT = Q / P^(-EPSD) ;
Formula SSHIFT = Q / P^EPSS ;

! Equations !
Equation E_DEMAND # Demand curve # Q = DSHIFT * P^(-EPSD) ;
Equation E_SUPPLY # Supply curve # Q = SSHIFT * P^EPSS ;

Points to note in the model file:

  • The four lines with DEFAULT say that equations and variables are in levels, and that formulas are used only to compute the starting values. TABLO turns the levels equations into percentage-change equations itself.
  • Each levels variable gets a percentage-change variable with the prefix p_. For example, the results for P are reported as p_P.
  • The price is read from the data file as the starting value of the variable P.

demand10.cmf

! Shift the demand curve up by 10 percent !
auxiliary files = market ;
file DATA = market.har ;
updated file DATA = <cmf>.upd ;
exogenous p_DSHIFT p_SSHIFT ;
rest endogenous ;
shock p_DSHIFT = 10 ;
method = gragg ;
steps = 2 4 6 ;
verbal description = Demand curve shifts up by 10 percent ;
log file = yes ;
  • The closure is the list of exogenous variables. Here the two shifters are exogenous and P and Q are endogenous.
  • The shock moves the demand curve up by 10%.
  • The updated file holds the data after the shock. It is needed because P is read from the data file.
  • The solution method is Gragg with 2, 4 and 6 steps. GEMPACK solves the model three times and extrapolates from the three answers.

Run it

In WinGEM. Choose File → Change both default directories and select the folder of this exercise. Choose Simulation → TABLO Implement, keep GEMSIM selected, open market.tab and click Run. Click Go to GEMSIM, open demand10.cmf and click Run. Then click Go to ViewSOL to see the results.

In the Command Prompt. Go to the folder of this exercise and type:

tablo -pgs market
gemsim -cmf demand10.cmf

Each program should end with (The program has completed without error.)
