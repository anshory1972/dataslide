Model B: income and rainfall

Files

Download model-b.zipdryyear.cmf, income5.cmf, marketb.har, marketb.tab

Unzip the file. It creates a folder model-b.

marketb.tab

! Model B: one market, demand depends on income, supply on rainfall !
!   Demand:  Q = DSHIFT * P^(-EPSD) * INC^EPSY                        !
!   Supply:  Q = SSHIFT * P^EPSS * RAIN^EPSR                          !

EQUATION (DEFAULT = LEVELS) ;
VARIABLE (DEFAULT = LEVELS) ;
FORMULA (DEFAULT = INITIAL) ;
COEFFICIENT (DEFAULT = PARAMETER) ;

File DATA # Transaction data, income, rainfall and elasticities # ;

! Elasticities !
Coefficient EPSD # Price elasticity of demand, as a positive number # ;
Coefficient EPSY # Income elasticity of demand # ;
Coefficient EPSS # Price elasticity of supply # ;
Coefficient EPSR # Rainfall elasticity of supply # ;
Read EPSD from file DATA header "EPSD" ;
Read EPSY from file DATA header "EPSY" ;
Read EPSS from file DATA header "EPSS" ;
Read EPSR from file DATA header "EPSR" ;

! Variables !
Variable P      # Price, Rp per kg # ;
Variable Q      # Quantity, billion kg # ;
Variable VALUE  # Value of transactions, Rp billion # ;
Variable INC    # Household income, Rp trillion # ;
Variable RAIN   # Rainfall, mm per year # ;
Variable DSHIFT # Other demand factors # ;
Variable SSHIFT # Other supply factors # ;

! Observed data !
Read P     from file DATA header "PRIC" ;
Read VALUE from file DATA header "VAL" ;
Read INC   from file DATA header "INC" ;
Read RAIN  from file DATA header "RAIN" ;

! Quantity follows from value and price !
Formula Q = VALUE / P ;

! Calibration: choose the shifters so that both curves pass through the data !
Formula DSHIFT = Q / [P^(-EPSD) * INC^EPSY] ;
Formula SSHIFT = Q / [P^EPSS * RAIN^EPSR] ;

! Equations !
Equation E_DEMAND # Demand curve # Q = DSHIFT * P^(-EPSD) * INC^EPSY ;
Equation E_SUPPLY # Supply curve # Q = SSHIFT * P^EPSS * RAIN^EPSR ;
Equation E_VALUE  # Value of transactions # VALUE = P * Q ;

income5.cmf

! Household income rises by 5 percent !
auxiliary files = marketb ;
file DATA = marketb.har ;
updated file DATA = <cmf>.upd ;
exogenous p_INC p_RAIN p_DSHIFT p_SSHIFT ;
rest endogenous ;
shock p_INC = 5 ;
method = gragg ;
steps = 2 4 6 ;
verbal description = Household income rises by 5 percent ;
log file = yes ;

dryyear.cmf

! Rainfall falls by 20 percent !
auxiliary files = marketb ;
file DATA = marketb.har ;
updated file DATA = <cmf>.upd ;
exogenous p_INC p_RAIN p_DSHIFT p_SSHIFT ;
rest endogenous ;
shock p_RAIN = -20 ;
method = gragg ;
steps = 2 4 6 ;
verbal description = Rainfall falls by 20 percent ;
log file = yes ;

The two command files have the same closure. Only the shock is different. You compile the model once with TABLO and run GEMSIM once for each command file.

Run it

In WinGEM. Choose File → Change both default directories and select the folder of this exercise. Choose Simulation → TABLO Implement, keep GEMSIM selected, open marketb.tab and click Run. Click Go to GEMSIM, open income5.cmf and click Run. Then click Go to ViewSOL to see the results.

In the Command Prompt. Go to the folder of this exercise and type:

tablo -pgs marketb
gemsim -cmf income5.cmf
gemsim -cmf dryyear.cmf

Each program should end with (The program has completed without error.)

Check by hand. Demand equals supply, so

Pεd+εs=D YηS RρP^{\varepsilon^{d}+\varepsilon^{s}} = \frac{D\,Y^{\eta}}{S\,R^{\rho}}Pεd+εs=SRρDYη​

When income rises by 5%: P1/P0=1.05η/(εd+εs)=1.050.2/0.8=1.0123P_1/P_0 = 1.05^{\eta/(\varepsilon^{d}+\varepsilon^{s})} = 1.05^{0.2/0.8} = 1.0123P1​/P0​=1.05η/(εd+εs)=1.050.2/0.8=1.0123.

When rainfall falls by 20%: P1/P0=0.8−ρ/(εd+εs)=0.8−0.3/0.8=1.0873P_1/P_0 = 0.8^{-\rho/(\varepsilon^{d}+\varepsilon^{s})} = 0.8^{-0.3/0.8} = 1.0873P1​/P0​=0.8−ρ/(εd+εs)=0.8−0.3/0.8=1.0873.

Higher income moves the demand curve, so price and quantity both rise. Lower rainfall moves the supply curve, so the price rises and the quantity falls.

Try this

  1. Write a third command file that shocks income by 5% and rainfall by −20% together.
  2. Change the closure so that the price is exogenous and DSHIFT is endogenous. Shock the price by 10%. The result for DSHIFT is the shift in demand that would explain a 10% higher price.
