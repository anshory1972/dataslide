Model D: a price subsidy

Model C with a tax or subsidy on each product. Consumers and producers face different prices. You learn to add a variable and an equation, and to shock a tax.

Arief Anshory Yusuf, Faculty of Economics and Business, Universitas Padjadjaran

The model

Demand depends on the consumer price PicP^{c}_iPic​. Supply depends on the producer price PipP^{p}_iPip​. A third equation links the two prices.

The other symbols are those of Model C.

The power of the tax is Ti=1+tiT_i = 1 + t_iTi​=1+ti​, where tit_iti​ is the tax rate. In the data there is no tax, so Ti=1T_i = 1Ti​=1 for every product. A subsidy of 10% means ti=−0.1t_i = -0.1ti​=−0.1 and Ti=0.9T_i = 0.9Ti​=0.9.

The shock is to TiT_iTi​, not to the tax rate. The tax rate starts at zero, and a percentage change of zero cannot be computed. A 10% subsidy moves TiT_iTi​ from 1 to 0.9, which is a change of −10%.

In the calibration, the producer price is computed from the data as Pi,0p=Pi,0c/Ti,0P^{p}_{i,0} = P^{c}_{i,0}/T_{i,0}Pi,0p​=Pi,0c​/Ti,0​. Then DiD_iDi​ is calibrated with the consumer price and SiS_iSi​ with the producer price.

The data

The data are those of Model C. The price in the data is the consumer price. The data file has one new header, PTAX, with the value 1 for each product.

Files

Download model-d.zipmarketd.har, marketd.tab, ricesub.cmf

Unzip the file. It creates a folder model-d.

marketd.tab

! Model D: Model C with an ad valorem tax or subsidy on each product  !
!   Demand:  Q(i) = DSHIFT(i) * PC(i)^(-EPSD(i)) * INC^EPSY(i)        !
!   Supply:  Q(i) = SSHIFT(i) * PP(i)^EPSS(i) * RAIN^EPSR(i)          !
!   Prices:  PC(i) = PP(i) * T(i)                                     !
!   T(i) is the power of the tax, 1 + tax rate. A subsidy has T < 1.  !

EQUATION (DEFAULT = LEVELS) ;
VARIABLE (DEFAULT = LEVELS) ;
FORMULA (DEFAULT = INITIAL) ;
COEFFICIENT (DEFAULT = PARAMETER) ;

File DATA # Transaction data, income, rainfall, tax and elasticities # ;

Set COM # Farm products # (Rice, Maize, Cassava, Vegetables, Fruits) ;

! Elasticities, one value for each product !
Coefficient (all,i,COM) EPSD(i) # Price elasticity of demand, positive # ;
Coefficient (all,i,COM) EPSY(i) # Income elasticity of demand # ;
Coefficient (all,i,COM) EPSS(i) # Price elasticity of supply # ;
Coefficient (all,i,COM) EPSR(i) # Rainfall elasticity of supply # ;
Read EPSD from file DATA header "EPSD" ;
Read EPSY from file DATA header "EPSY" ;
Read EPSS from file DATA header "EPSS" ;
Read EPSR from file DATA header "EPSR" ;

! Variables for each product !
Variable (all,i,COM) PC(i)     # Consumer price, Rp per kg # ;
Variable (all,i,COM) PP(i)     # Producer price, Rp per kg # ;
Variable (all,i,COM) T(i)      # Power of the tax, 1 + tax rate # ;
Variable (all,i,COM) Q(i)      # Quantity, billion kg # ;
Variable (all,i,COM) VALUE(i)  # Value at consumer prices, Rp billion # ;
Variable (all,i,COM) DSHIFT(i) # Other demand factors # ;
Variable (all,i,COM) SSHIFT(i) # Other supply factors # ;

! Variables shared by all products !
Variable INC  # Household income, Rp trillion # ;
Variable RAIN # Rainfall, mm per year # ;

! Observed data !
Read PC    from file DATA header "PRIC" ;
Read T     from file DATA header "PTAX" ;
Read VALUE from file DATA header "VAL" ;
Read INC   from file DATA header "INC" ;
Read RAIN  from file DATA header "RAIN" ;

Formula (all,i,COM) PP(i) = PC(i) / T(i) ;
Formula (all,i,COM) Q(i) = VALUE(i) / PC(i) ;

! Calibration !
Formula (all,i,COM) DSHIFT(i) = Q(i) / [PC(i)^(-EPSD(i)) * INC^EPSY(i)] ;
Formula (all,i,COM) SSHIFT(i) = Q(i) / [PP(i)^EPSS(i) * RAIN^EPSR(i)] ;

! Equations, one of each for every product !
Equation E_DEMAND # Demand curve, consumer price #
  (all,i,COM) Q(i) = DSHIFT(i) * PC(i)^(-EPSD(i)) * INC^EPSY(i) ;
Equation E_SUPPLY # Supply curve, producer price #
  (all,i,COM) Q(i) = SSHIFT(i) * PP(i)^EPSS(i) * RAIN^EPSR(i) ;
Equation E_PRICE  # Consumer price = producer price x power of tax #
  (all,i,COM) PC(i) = PP(i) * T(i) ;
Equation E_VALUE  # Value at consumer prices #
  (all,i,COM) VALUE(i) = PC(i) * Q(i) ;

Compare this file with marketc.tab. There are two new variables, PP and T, and one new equation, E_PRICE. The producer price is computed from the data with a formula.

ricesub.cmf

! A 10 percent price subsidy on rice !
auxiliary files = marketd ;
file DATA = marketd.har ;
updated file DATA = <cmf>.upd ;
exogenous p_INC p_RAIN p_DSHIFT p_SSHIFT p_T ;
rest endogenous ;
shock p_T("Rice") = -10 ;
method = gragg ;
steps = 2 4 6 ;
verbal description = A 10 percent price subsidy on rice ;
log file = yes ;

T is exogenous. Only the rice element is shocked.

Run it

In WinGEM. Choose File → Change both default directories and select the folder of this exercise. Choose Simulation → TABLO Implement, keep GEMSIM selected, open marketd.tab and click Run. Click Go to GEMSIM, open ricesub.cmf and click Run. Then click Go to ViewSOL to see the results.

In the Command Prompt. Go to the folder of this exercise and type:

tablo -pgs marketd
gemsim -cmf ricesub.cmf

Each program should end with (The program has completed without error.)

The subsidy lowers the consumer price by 3.9% and raises the producer price by 6.8%. Producers receive the larger part, because supply (elasticity 0.3) is less elastic than demand (elasticity 0.5).

Open ricesub.upd in ViewHAR. The header PTAX now has 0.9 for rice.
