Install GEMPACK

Please install GEMPACK on your laptop before the session on Sunday, 22 November 2026. This page gives the download links and the steps.

Arief Anshory Yusuf, Faculty of Economics and Business, Universitas Padjadjaran

What you need

  • A laptop with Windows 7 or later. GEMPACK does not run on macOS or Linux unless Windows is installed.
  • At least 4 GB of free disk space on drive C, and at least 4 GB of memory.
  • Administrator rights on the laptop. Windows asks for them during the installation.

Downloads

The free version is the trial of the Limited Executable-Image Version of GEMPACK, release 12.2.001. It is published by the Centre of Policy Studies, Victoria University, Melbourne.

GEMPACK installer (.exe) gpei-12.2.001-install.exe · about 100 MB Same installer in a .zip file Use this if your browser or network blocks .exe files Short install guide (PDF) quickinst.pdf · 6 pages · the steps below follow it Official download page copsmodels.com/gpeidl.htm

The licence lasts 6 months from the day you download. It is free and the installer creates it. You do not need to register. After 6 months, ViewHAR and ViewSOL still open files, but you cannot run new simulations.

Install in five steps

  1. Check for an old copy. If the folder C:\GP already exists, rename it to C:\GPOLD.
  2. Download the installer. Save gpei-12.2.001-install.exe. If you downloaded the .zip file, extract the .exe from it first.
  3. Run the installer. Double-click the .exe file. If Windows asks for permission, click Yes.
  4. Accept the default settings.
    • Licence agreement: click I agree, then Next.
    • Destination folder: keep C:\GP.
    • Changes to PATH and GPDIR: accept them.
    • Licence file: you have none, so click Next. The installer creates the 6-month licence.
  5. Finish. Click Finish. If Windows says the program might not have installed correctly, choose This program installed correctly.

Test the installation

This test takes about 5 minutes. It runs a small model that comes with GEMPACK. Please do it before the session.

  1. Open WinGEM from the desktop icon. It appears as a menu bar at the top of the screen.
  2. Choose Options → Check GEMPACK licence. A window should show your licence details.
  3. Choose File → Change both default directories. Go to C:\GP\examples and click Select Folder.
  4. Choose Simulation → TABLO Implement. Make sure GEMSIM is selected. Click Select, open SJ.TAB, and click Run.
  5. Click Go to GEMSIM. Click Select, open SJLB.CMF, and click Run.
  6. A small window with a bar chart and two smiling faces should appear. This means your installation works.

You can also run the same test in the Command Prompt:

cd C:\GP\examples
tablo -pgs sj
gemsim -cmf sjlb.cmf

Both programs should end with the line (The program has completed without error.)

If something goes wrong

  • Your Windows user name has spaces or non-English letters. This often causes errors. Create the folders C:\TEMP and C:\GPKEEP. In Environment Variables, set the user variables TMP and TEMP to C:\TEMP. Add a user variable GPKEEP with the value C:\GPKEEP. Then restart the laptop.
  • Your antivirus deletes or blocks GEMPACK programs. Mark the folder C:\GP as safe in the antivirus settings. See copsmodels.com/gpconfav.htm.
  • It still does not work. Read section 4 of the short install guide or the full install guide. Then contact the committee before the session.
