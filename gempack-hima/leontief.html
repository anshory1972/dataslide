GEMPACK for Students · Part 6

Leontief model with BPS data

An input-output model with the 2020 input-output table of Indonesia, 17 products. You learn to bring data from Excel into GEMPACK, compute an output multiplier, and check the model against the BPS table.

Arief Anshory Yusuf, Faculty of Economics and Business, Universitas Padjadjaran

The model

Xi=∑j∈SECaij Xj+Fi,aij=ZijXj,i∈SECX_i = \sum_{j \in \text{SEC}} a_{ij}\,X_j + F_i, \qquad a_{ij} = \frac{Z_{ij}}{X_j}, \qquad i \in \text{SEC}Xi​=j∈SEC∑​aij​Xj​+Fi​,aij​=Xj​Zij​​,i∈SEC
SymbolMeaningName in the model file
XiX_iXi​Output of sector iX(i)
FiF_iFi​Final demand for product iF(i)
ZijZ_{ij}Zij​Flow of product i used by sector jZ(i,j)
aija_{ij}aij​Input coefficient, fixedA(i,j)
Xtot=∑iXiX^{\text{tot}} = \sum_i X_iXtot=∑i​Xi​Total output of all sectorsXTOT

SEC is the set of the 17 sectors. In matrix form the model is

X=A X+F⟹X=(I−A)−1 FX = A\,X + F \quad\Longrightarrow\quad X = (I - A)^{-1}\,FX=AX+F⟹X=(I−A)−1F

(I−A)−1(I - A)^{-1}(I−A)−1 is the Leontief inverse. The model is linear, so the Johansen method gives the exact answer in one step.

Step 1. Download the table from BPS

  1. Open the BPS page Tabel Input-Output Indonesia Transaksi Domestik atas Dasar Harga Dasar (17 Produk), 2020 (Juta Rupiah). The table takes about 10 seconds to appear.
  2. Click the green Unduh button next to Kembali and choose the Excel file. No login is needed.
  3. Put the file in the folder of this exercise and rename it bpsio.xls. The short name avoids problems with spaces and brackets.

In the file, the flows are in cells D6:T22, total final demand is in column AC and output is in column AN. All values are in million rupiah.

Step 2. Copy the data into a GEMPACK data file

Close the file in Excel first. Then type in the Command Prompt, in the folder of this exercise:

xls2head bpsio.xls 1 17 17 6 4 ZMAT io2020.har
xls2head bpsio.xls 1 17 1 6 29 FDEM io2020.har
xls2head bpsio.xls 1 17 1 6 40 XOUT io2020.har

The numbers mean: worksheet 1, a block of 17 rows and 17 (or 1) columns, starting at row 6 and column 4 (or 29, or 40). The last two words are the header name and the data file. The three commands copy the flows, total final demand and output.

Open io2020.har in ViewHAR and check the first value of ZMAT. It should be 177,950,421, the same as cell D6 in Excel.

If xls2head does not work on your laptop, use the file io2020.har in the download. It was made with the same three commands.

Part A. The output multiplier

leontief.tab

! Leontief input-output model, BPS 2020 domestic table, 17 products     !
!   X(i) = sum{j, A(i,j)*X(j)} + F(i)                                   !
!   A(i,j) = Z(i,j)/X(j), fixed input coefficients                      !

EQUATION (DEFAULT = LEVELS) ;
VARIABLE (DEFAULT = LEVELS) ;
FORMULA (DEFAULT = INITIAL) ;
COEFFICIENT (DEFAULT = PARAMETER) ;

File DATA # BPS input-output table, million rupiah # ;

Set SEC # Sectors, in the BPS order #
 (Agri, Mining, Manuf, Electric, Water, Constr, Trade, Transport, AccomFood,
  InfoComm, Finance, RealEstate, Business, PublicAdm, Education, Health, OtherServ) ;

! Data from BPS, in million rupiah !
Coefficient (all,i,SEC)(all,j,SEC) ZRAW(i,j) # Intermediate flow from i to j, Rp million # ;
Coefficient (all,i,SEC)            FRAW(i)   # Final demand, Rp million # ;
Read ZRAW from file DATA header "ZMAT" ;
Read FRAW from file DATA header "FDEM" ;

! Convert to trillion rupiah !
Coefficient (all,i,SEC)(all,j,SEC) Z(i,j) # Intermediate flow from i to j, Rp trillion # ;
Formula (all,i,SEC)(all,j,SEC) Z(i,j) = ZRAW(i,j) / 1000000 ;

! Output and final demand are ordinary changes in Rp trillion, !
! so the results are the multipliers directly.                 !
Variable (levels, change) (all,i,SEC) X(i) # Total output, Rp trillion # ;
Variable (levels, change) (all,i,SEC) F(i) # Final demand, Rp trillion # ;
Variable (levels, change) XTOT # Total output of all sectors, Rp trillion # ;
Formula (all,i,SEC) F(i) = FRAW(i) / 1000000 ;

! Output = intermediate sales + final demand !
Formula (all,i,SEC) X(i) = sum{j, SEC, Z(i,j)} + F(i) ;
Formula XTOT = sum{i, SEC, X(i)} ;

! Calibration: input coefficients !
Coefficient (all,i,SEC)(all,j,SEC) A(i,j) # Input of i per unit of output of j # ;
Formula (all,i,SEC)(all,j,SEC) A(i,j) = Z(i,j) / X(j) ;

Equation E_X # Output = intermediate sales + final demand #
  (all,i,SEC) X(i) = sum{j, SEC, A(i,j) * X(j)} + F(i) ;
Equation E_XTOT # Total output #
  XTOT = sum{i, SEC, X(i)} ;
  • The 17 sector names are written in the model file. The BPS names have spaces and commas, which GEMPACK does not allow in set elements.
  • The data stay in million rupiah in the data file. The model converts them to trillion rupiah with a formula.
  • X, F and XTOT are change variables, declared with (levels, change). Their results are ordinary changes in Rp trillion, with the prefix c_, not percentage changes.

agri1.cmf

! Final demand for agriculture rises by Rp 1 trillion !
auxiliary files = leontief ;
file DATA = io2020.har ;
exogenous c_F ;
rest endogenous ;
shock c_F("Agri") = 1 ;
method = johansen ;
verbal description = Final demand for agriculture rises by Rp 1 trillion ;
log file = yes ;

Final demand for agriculture rises by Rp 1 trillion. Final demand for the other 16 products does not change. The command file has no updated file, because no variable is read from the data file.

Run it.

In WinGEM. Choose File → Change both default directories and select the folder of this exercise. Choose Simulation → TABLO Implement, keep GEMSIM selected, open leontief.tab and click Run. Click Go to GEMSIM, open agri1.cmf and click Run. Then click Go to ViewSOL to see the results.

In the Command Prompt. Go to the folder of this exercise and type:

tablo -pgs leontief
gemsim -cmf agri1.cmf

The change in output is

ΔX=(I−A)−1 ΔF,ΔF=(1,0,…,0)⊤\Delta X = (I - A)^{-1}\,\Delta F, \qquad \Delta F = (1, 0, \dots, 0)^{\top}ΔX=(I−A)−1ΔF,ΔF=(1,0,…,0)⊤

Because the shock is 1 for agriculture and 0 for the other sectors, each ΔXi\Delta X_iΔXi​ is one element of the agriculture column of the Leontief inverse. The output multiplier is the column sum:

mAgri=∑iΔXi=ΔXtot=1.294m_{\text{Agri}} = \sum_i \Delta X_i = \Delta X^{\text{tot}} = 1.294mAgri​=i∑​ΔXi​=ΔXtot=1.294

One trillion rupiah more final demand for agriculture raises total output by Rp 1.294 trillion.

Part B. Check the model against the BPS table

In Excel you can compute output as the Leontief inverse times final demand, and compare it with the BPS output. This part does the same in GEMPACK.

TABLO has no function to invert a matrix. GEMPACK solves the equations instead, and the result is the same.

The Leontief model has no constant term. So X=0X = 0X=0 with F=0F = 0F=0 is a solution. The model starts from this solution and final demand is shocked from zero to the BPS values FBPSF^{\text{BPS}}FBPS. The change in output is then

ΔX=(I−A)−1 (FBPS−0)=(I−A)−1 FBPS\Delta X = (I - A)^{-1}\,\bigl(F^{\text{BPS}} - 0\bigr) = (I - A)^{-1}\,F^{\text{BPS}}ΔX=(I−A)−1(FBPS−0)=(I−A)−1FBPS

It should equal the output in the BPS table, XBPSX^{\text{BPS}}XBPS. The input coefficients are aij=Zij/XjBPSa_{ij} = Z_{ij}/X^{\text{BPS}}_jaij​=Zij​/XjBPS​.

leontief0.tab

! Leontief model solved from zero: output = inverse x final demand  !
! Same calculation as MINVERSE and MMULT in Excel                    !

EQUATION (DEFAULT = LEVELS) ;
COEFFICIENT (DEFAULT = PARAMETER) ;
FORMULA (DEFAULT = INITIAL) ;

File DATA # BPS IO table 2020, 17 products, Rp million # ;

Set SEC # Sectors, in the BPS order #
 (Agri, Mining, Manuf, Electric, Water, Constr, Trade, Transport, AccomFood,
  InfoComm, Finance, RealEstate, Business, PublicAdm, Education, Health, OtherServ) ;

Coefficient (all,i,SEC)(all,j,SEC) Z(i,j) # Flows, Rp million # ;
Coefficient (all,i,SEC) XDATA(i) # Output in the BPS table, Rp million # ;
Read Z     from file DATA header "ZMAT" ;
Read XDATA from file DATA header "XOUT" ;

Coefficient (all,i,SEC)(all,j,SEC) A(i,j) # Input coefficients # ;
Formula (all,i,SEC)(all,j,SEC) A(i,j) = Z(i,j) / XDATA(j) ;

Variable (levels, change) (all,i,SEC) X(i) # Output, Rp million # ;
Variable (levels, change) (all,i,SEC) F(i) # Final demand, Rp million # ;

! Start from zero output and zero final demand !
Formula (all,i,SEC) X(i) = 0 ;
Formula (all,i,SEC) F(i) = 0 ;

Equation E_X # Output = intermediate demand + final demand #
  (all,i,SEC) X(i) = sum{j, SEC, A(i,j) * X(j)} + F(i) ;
  • The input coefficients are computed from the BPS flows and the BPS output (header XOUT).
  • Output and final demand start at zero. They are given the value zero by a formula, not read from the data file.
  • All values are in million rupiah, as in the BPS table, so the results can be compared with the table directly.

fullfd.cmf

! Final demand rises from zero to the BPS values !
auxiliary files = leontief0 ;
file DATA = io2020.har ;
exogenous c_F ;
rest endogenous ;
shock c_F = file io2020.har header "FDEM" ;
method = johansen ;
verbal description = Final demand from zero to BPS values ;
log file = yes ;

The shock statement reads all 17 values of final demand from header FDEM of the data file.
