7 · Method

Data and definitions

  • Source. OpenAlex API only, snapshot . Works of type article whose primary location is a journal, published 2000–2025.
  • Share. Articles with exactly one author divided by articles with at least one author (authors_count).
  • Field. The primary topic of each article in the OpenAlex classification: 26 fields, 252 subfields, about 4,500 topics. Articles are classified, not journals.
  • Top-quarter journals. Journals with 50 or more works, and 20 or more works in 2024–25, are ranked by 2-year mean citations (2yr_mean_citedness) within their main subfield, the subfield of their largest topic. Subfields with fewer than ten ranked journals are ranked within their field. The top 25% form the tier: journals.
  • Reference screen. Book reviews, editorials and short notes are often typed as articles and are mostly single-authored. Every share is also shown for articles with at least five references.
  • Theoretical physics. Six OpenAlex topics: .

Limits

  • The journal ranking uses 2026 citation figures and is applied to all years. A journal that was weaker in 2005 counts as top quarter in 2005.
  • OpenAlex topics come from a classifier. Some articles sit in an unexpected topic.
  • The top quarter holds about 20,000 journals, of which 12,000 are also OpenAlex core journals. It can include some weaker journals with high citation counts.
  • OpenAlex changes over time. A new run gives slightly different numbers unless the original cache is used.

8 · Replicate

Code and data

Everything on this page comes from four Python scripts and the OpenAlex API. The package holds the code, the processed counts and the result tables.

Download the package (zip, MB)

Files in the package

    Steps

    1. Install Python 3.10 or newer, unzip the package, and install three packages: 
      cd authorship-study
pip install -r requirements.txt
    2. Rebuild the tables and this page from the included counts. No API key is needed for this step: 
      cd analysis/authorship_oa
python 03_tables.py
python 04_report.py
      The results are in out/authorship_oa/tables/ and the page is out/authorship_oa/single-authorship.html.
    3. To pull the data again from OpenAlex, get a free API key at openalex.org (account settings). Copy .env.example to .env in the authorship-study folder and put the key in it: 
      OPENALEX_API_KEY=your_key_here
    4. Delete the folder data/authorship_oa/processed, then run the four scripts in order: 
      python 01_journals.py
python 02_counts.py
python 03_tables.py
python 04_report.py
      01_journals.py downloads about 154,000 journals, ranks them and creates the top-quarter collection in your OpenAlex account (about 800 credits). 02_counts.py runs the counts by subfield, year and topic (about 1,300 credits). A free key has 10,000 credits a day. Every query is cached under data/authorship_oa/raw/, so a stopped run continues where it stopped.
    5. To change the design, edit config.py (periods, the 25% cut-off, minimum journal size) or the topic list THEORY_TOPICS in 03_tables.py, and run again from step 01.
    Data: OpenAlex (CC0). Built by Arief Anshory Yusuf. The page is self-contained and works offline once loaded. Source at github.com/anshory1972/dataslide.
