A dynamic DTSEN could cut inclusion error by half

In the pilot, applicants enter their data only when they file a grievance. For a dynamic DTSEN, data entry should happen at registration, with a much shorter list of variables.
Dynamic DTSEN decile (upper bound)
IE = households receiving BPNT that are in Susenas decile 5–10 ÷ all households receiving. Weighted household counts. BPNT, Bali, Susenas March 2025; the pilot is treated as if run in March 2025. Source: KPTDP Targeting Team, DPI pilot evaluation (draft, preliminary). Dynamic DTSEN decile: a short proxy means test (8 variables, district effects) on current Susenas data, an upper bound.
