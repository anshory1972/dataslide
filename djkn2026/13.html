Linearized form (% change)
TABLO code (GEMPACK)
1ki = xi − σi(r − ci)
1k(i) = x(i) - sigma(i)*(r-c(i));
2li = xi − σi(w − ci)
2l(i) = x(i) - sigma(i)*(w-c(i));
3ci = SLi w + (1 − SLi) r
3c(i) = SL(i)*w + (1-SL(i))*r;
4PiXi(pi + xi) = WLi(w + li) + RKi(r + ki)
4PX(i)*(p(i)+x(i)) = WL(i)*(w+l(i))+RK(i)*(r+k(i));
5qi = y − pi
5q(i) = y - p(i);
6Y·y = WLS(w + lS) + RKS(r + kS)
6VY*y = WLS*(w+ls)+RKS*(r+ks);
7WLS·lS = Σi WLi·li
7WLS*ls = SUM(i,IND, WL(i)*l(i));
8xi = qi
8x(i) = q(i);
Redrawn from A. A. Yusuf, CGE Modeling with GEMPACK (Padang course), p. 20. One line of TABLO covers both industries: (i) runs over corn and meat.
